Промпт для Qwen Image


      


Seed задаёт исходный случайный шум. При одинаковых модели, промпте, настройках и режиме вычислений фиксированный seed позволяет повторить результат; другой seed меняет композицию и детали. Номер seed не влияет на качество или скорость. В серии он увеличивается на 1.
Guidance: 1.0 · режим текущего движка. Длина промпта проверяется по лимиту энкодера; слишком длинный ввод не обрезается молча.

      


Промпт для Qwen Image
Опишите готовую сцену: что изображено, где расположено и как выглядит.
  1. Сюжет и формат: фотография, иллюстрация, плакат.
  2. Главный объект, поза или действие, количество объектов.
  3. Композиция: передний план, фон, положение в кадре.
  4. Цвета, материалы, фактура.
  5. Источник, направление и мягкость света.
  6. Надписи — точно в кавычках, с указанием места.
Пример: Реалистичная фотография рыжего котёнка на деревянном подоконнике. Котёнок слева, смотрит в камеру; справа свободное пространство. За окном размытый зелёный сад. Мягкий утренний свет справа, тёплые оттенки, видна фактура шерсти.
Не обязательно писать длинный шаблон. Начните с замысла; «Улучшить промпт» может дополнить его. Конкретные детали полезнее слов «шедевр» и «8K».

Документы LES


Поиск выполняется в LES. В выбранный сервис отправляется запрос модели; найденные фрагменты используются для ответа. Для этого модель должна поддерживать инструменты.




Добавление документов и индексация остаются в LES. Для его штатного stdio-шлюза используйте подключение через API.
